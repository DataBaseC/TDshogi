### 第三轮（2026-09-28）· §4.1 前端拆分收尾

前端没有模块系统（`<script>` 顺序装配全局），拆文件的最大风险是**静默失效**：
顺序写反 / 注入没生效 / 引用了已搬走的符号 —— 页面照常渲染、控制台干净，只是"点了没反应"。
因此本轮先补**验证网**，再动手拆。

**新建页面级测试脚手架（`tests/helpers/page.js`）**
- 把"一个页面"搬进 Node：按 `public/*.html` 里 `<script>` 的**原样顺序**跑一遍，
  用 Proxy 造万能 `window` 替身 + 结构化 `document` 桩（`firstChild` 用 getter 反映 children，
  否则 `while(el.firstChild)` 会死循环）；定时器一律空实现（真 `setInterval` 会把测试进程吊住）。
- `tests/page-load.test.js`（11 项）：10 个页面逐个"按序加载不抛错 + 关键全局到位"。
- `tests/play-views.test.js`（4 项）：**运行期**真调渲染层（渲染链、玩家栏写入、观战视角切换）。
- `tests/admin-tabs.test.js`（3 项）：管理后台 7 个 tab 模块已装配、跨模块加载器都挂在 window、
  每个加载器真调一次。
- 反向验证：故意把 `freeboard-dnd.js` 从 `play.html` 去掉 → 测试立刻报
  「freeboard-dnd.js 必须在 freeboard.js 之前加载」✓ 护栏可信。
